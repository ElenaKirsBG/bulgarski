# Български език — курс болгарского языка для iPhone

Приложение-курс болгарского языка для русскоговорящих. Работает на iPhone и iPad как обычное приложение с иконкой на экране «Домой», в том числе без интернета.

**Что внутри**

- 46 уроков в пяти частях: звуки и буквы → первые шаги (A1) → времена и наклонения (A2) → продвинутая грамматика (B1) → речевые ситуации. В каждом уроке — цель, теория с таблицами, примеры с переводом, диалоги, словарик и тест.
- Ударения во всех многосложных словах (можно показывать знаком, цветом или скрыть). Ударения сверены с учебниками Ивановой–Шановой–Димитровой и Даниловой.
- Болгарско-русский и русско-болгарский словарь (~2100 статей): поиск по любой форме слова; у глаголов — спряжение во всех временах (настоящее, аорист, имперфект, перфект, будущее, повелительное, условное, пересказывательное), у существительных — формы с артиклем, множественное и счётное число, у прилагательных — все роды и артикль.
- 14 справочных таблиц, включая вашу таблицу глаголов (проверенную).
- Карточки с интервальным повторением по наборам (тема, часть речи, свои слова).
- Озвучка болгарским голосом iPhone; нажатие на любое слово в примере открывает его в словаре.
- Настройки: тема оформления, размер шрифта, ударения, перевод примеров (режим самопроверки), резервная копия прогресса.

## Как опубликовать на GitHub (пошагово)

Понадобится только браузер — на компьютере удобнее, но можно и с iPhone.

1. **Аккаунт.** Зайдите на github.com и войдите (или зарегистрируйтесь — кнопка *Sign up*).
2. **Новый репозиторий.** Нажмите «+» в правом верхнем углу → *New repository*.
   - *Repository name*: например `bulgarski`.
   - Выберите **Public** (бесплатные страницы GitHub Pages работают для публичных репозиториев).
   - Нажмите *Create repository*.
3. **Загрузите файлы.** На странице нового репозитория нажмите ссылку *uploading an existing file*.
   - Распакуйте архив `bulgarski-app.zip` на компьютере.
   - Перетащите в окно браузера **всё содержимое** папки (файлы `index.html`, `app.js`, `manifest.webmanifest`, `sw.js`, `README.md`, `LICENSE` и папки `data` и `icons`). Важно: `index.html` должен оказаться в корне репозитория, а не внутри дополнительной папки.
   - Внизу нажмите *Commit changes*.
4. **Включите GitHub Pages.** В репозитории: *Settings* → слева *Pages* → в разделе *Build and deployment* выберите *Source: Deploy from a branch*, *Branch: main*, папка */ (root)* → *Save*.
5. **Подождите 1–2 минуты** и обновите страницу *Pages*: вверху появится адрес вида `https://ВАШ-ЛОГИН.github.io/bulgarski/`.
6. **Установите на iPhone.** Откройте этот адрес в **Safari** → кнопка «Поделиться» (квадрат со стрелкой) → *На экран «Домой»* → *Добавить*. На экране появится иконка «Български». То же самое можно сделать на iPad.
7. **Включите болгарский голос.** На iPhone: *Настройки → Универсальный доступ → Устный контент → Голоса → Болгарский* → загрузите голос (например, *Daria*). После этого в приложении работают кнопки озвучки.

## Как обновлять

Если вы поменяли какой-то файл (например, добавили слова в `data/dict-5.js`):
1. В репозитории откройте нужный файл → значок карандаша (*Edit*) или загрузите новую версию через *Add file → Upload files*.
2. Откройте `sw.js` и увеличьте номер версии в строке `const CACHE = 'bg-course-v1';` (например, на `v2`) — так iPhone скачает обновление.
3. *Commit changes*. Через минуту-две откройте приложение заново.

## Как устроены данные

- `data/course-1.js` … `course-4.js` — уроки (простая разметка: `##` — заголовок, `>` — пример, `D:` — реплика диалога, `W:` — слово, `Q:` — вопрос теста).
- `data/dict-1.js` … `dict-5.js` — словарь, одна строка — одна статья: `слово | часть речи | перевод | грамматика`.
- `data/grammar.js` — справочные таблицы.

Прогресс уроков и карточек хранится на устройстве. Чтобы перенести его на другое устройство, используйте *Настройки → Сохранить копию / Загрузить копию*.
